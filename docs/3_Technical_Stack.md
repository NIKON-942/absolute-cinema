# Technical Stack

## 1. Programming Languages
* **TypeScript (v5.4+):** Used universally across both the client and server applications to provide strict static typing, reduce runtime errors, and facilitate easier refactoring.

## 2. Frontend (Client-Side)
* **Framework/Library:** React (chosen for its component-based approach and efficient virtual DOM rendering).
* **Environment:** Web browsers (Google Chrome 120+, Mozilla Firefox 115 ESR+, Apple Safari 16.0+, Microsoft Edge 120+).
* **Standards:** HTML5 Video, CSS3, JavaScript (ES2022+).

## 3. Backend (Server-Side)
* **Runtime Environment:** Node.js (v18.x LTS or higher).
* **Framework:** NestJS (chosen for its modular architecture, strict structural guidelines, and native TypeScript support).
* **ORM:** TypeORM (for deep integration with TypeScript decorators and PostgreSQL).

## 4. Database
* **Relational DBMS:** PostgreSQL (v14 or higher). Chosen for its robust ACID compliance, which is critical for handling financial transactions and managing complex relational metadata (movies, genres, actors).

## 5. Development Tools & Environments
* **IDE:** Visual Studio Code (v1.90+).
* **Version Control:** Git.
* **Repository Hosting:** GitHub.

## 6. Server Requirements
* **OS:** Unix/Linux family (Debian 12 or Ubuntu 22.04 LTS+).
* **Minimum Hardware:** 4-core CPU (2.5 GHz+), 8 GB RAM, 500 GB NVMe SSD, 1 Gbps network.
* **Recommended Hardware:** 8-core CPU (3.0 GHz+), 16 GB RAM (for efficient caching), 1 TB NVMe SSD, 10 Gbps network.
